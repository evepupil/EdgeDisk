# 搜索与治理

- **模块定位**：提供跨目录检索、全局分享管理和导入任务控制。
- **对应代码**：规划中，预计涉及 `src/server/`、`src/db/` 与 `app/`
- **所属 M 里程碑**：[M2](../roadmap.md#m2)
- **当前状态**：未开始
- **最近更新时间**：2026-07-24

## 职责与边界

该模块负责需要新增服务端能力的管理功能。当前目录即时筛选属于 M1，全盘检索属于本模块。

## 结构与数据流

规划通过服务端索引或受控遍历提供搜索结果，通过独立 API 汇总分享记录，并为 Queue 任务补充取消和重试状态流转。

## 关键决策

- 在明确 R2 对象规模和查询频率后再选择搜索索引方案。
- 全局分享列表需要可靠的索引，不能依赖客户端逐个目标查询。
- 任务取消必须定义排队中和执行中的不同语义。

## 当前实现

尚未开始。现有服务端仅支持目录列表、按目标查询分享，以及查看导入任务状态。

## 验证方式

- 为搜索、分享索引和任务状态转换编写服务端单元测试。
- 使用本地绑定执行接口集成测试。

## 待扩展项

- 搜索结果高亮与过滤器。
- 分享访问统计和批量撤销。
- 导入任务保留策略。
