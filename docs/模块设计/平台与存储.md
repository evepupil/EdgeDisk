# 平台与存储

- **模块定位**：提供 EdgeDisk 的服务端运行环境、文件存储和异步任务基础。
- **对应代码**：`src/server/`、`src/db/`、`migrations/`、`wrangler.jsonc`
- **所属 M 里程碑**：[M0](../roadmap.md#m0)
- **当前状态**：已完成
- **最近更新时间**：2026-07-24

## 职责与边界

该模块负责 Access 身份校验、R2 文件读写、KV 分享记录、D1 任务与回收站记录、Queue 异步 URL 导入。浏览器页面布局和交互由 M1 前端模块负责。

## 结构与数据流

后台页面通过 `/api/*` 调用 Hono API。API 校验请求后交给 service 或存储函数，最终访问 R2、KV、D1 与 Queue。公开分享页通过 `/share-api/:code` 读取分享内容，通过 `/s/:code/file` 读取文件流。

## 关键决策

- 文件内容保存在 R2，目录通过前缀和空目录标记表达。
- 分享短链保存在 KV，并维护目标到分享码的反向索引。
- URL 导入采用 Queue 异步处理，D1 保存可查询的任务状态。
- 删除操作先进入回收站，彻底删除由单独接口完成。

## 当前实现

现有接口覆盖目录浏览、上传、创建文件夹、移动或重命名、详情、分享、回收站和 URL 导入。M1 重设计沿用这些接口，不修改存储模型。
